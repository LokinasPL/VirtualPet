Auteur : Lokinas Peter Lemire

Date : Novembre 2024

Description : Ce projet nous demandait de créer un jeux vidéo simple en utilisant le module pygame. On a choisit de créer un jeux de style tamagotchi simple, où des statistiques attachées à un "animal" changeaient à travers le temps et pouvaient être influencées par les actions du joueurs (peser sur des boutons).
